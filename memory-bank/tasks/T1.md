## Bianchi I Validation (2026-07-21)

- Added `scripts/bianchi-telegraph-validation.mjs`, invoked with `pnpm validate:bianchi-telegraph`; `--output <path>` writes the complete density fields and coordinates.
- The headless runner uses seeded Monte Carlo persistent walks in $(\beta_+,\beta_-)$, with $\alpha$ as simulation time, and solves $u_{\alpha\alpha}+2\lambda u_\alpha=v^2\Delta_\beta u$ on the same absorbing grid, domain, and initial disk.
- The tested stochastic mapping uses $B=-2\lambda$ and rejects $B>0$.
- Default matched calibration: $N=20000$, $64^2$ cells, $v=\lambda=1$, $B=-2$, $\alpha=1.2$. It has zero finite-speed-front violations, but $L^1=0.9454$ and $L^2=0.4025$.
- Refinement $(32^2,5000)\to(64^2,20000)\to(96^2,45000)$ gives $L^1=(1.0337,0.9541,1.0215)$ and $L^2=(0.4431,0.4037,0.4423)$. The measured errors are non-monotone across these levels.
- The reported comparison does not include a derived 2D velocity-state closure or a separately calibrated rate mapping.

## Bianchi IX Potential Results (2026-07-21)

- Added the standard dimensionless Misner potential $V_{IX}(\beta_+,\beta_-)$ to the headless solver in the convention $u_{\alpha\alpha}+2\lambda u_\alpha=v^2\Delta_\beta u-e^{4\alpha}V_{IX}u$. Run `pnpm validate:bianchi-ix`.
- The runner uses the $e^{4\alpha}V_{IX}$ normalization. The manuscript expression currently uses $-24\pi^2e^{6\alpha}R$; this runner does not implement a conversion between them.
- Its source coefficient $q=-e^{4\alpha}V_{IX}$ changes sign. In the bounded diagnostic it ranges from $-734.916$ to $0.00819$ and changes the total field mass.
- For $\Delta\alpha=0.01,0.005,0.0025$, the field minimum is $-0.6764$. The diagnostics report `positiveFixedPopulation: false`, `positiveBranchingPopulation: false`, and a signed-weight ensemble representation.

- Five Bianchi validation tests cover seeded reproducibility, parameter constraints, finite density metrics/front checks, Bianchi IX source/sink diagnostics, and refinement output. They passed in the local 16-file, 62-test Vitest run on 2026-09-29.
