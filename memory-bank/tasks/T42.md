## Description
Make the existing Random Walk page panels individually manageable and keep their layout across reloads. Add particle-view zoom and a clear indication of finite container boundaries, and use one state-aware Start/Pause/Resume control. Extend existing grid, floating-panel, rendering, and persistence patterns without adding a UI framework or a separate Random Walk page or engine.

## Acceptance Criteria
- [ ] Every Random Walk panel, including Strategy Diagnostics and persistent-walk diagnostics, can be moved, resized, and collapsed using the existing panel patterns.
- [ ] Panel positions, sizes, and collapsed states persist through the existing app store.
- [ ] The particle viewport supports zoom without changing simulated particle coordinates.
- [ ] Finite particle-container boundaries are clearly visible; unbounded runs are identified without drawing a physical boundary.
- [ ] One state-aware control provides Start, Pause, and Resume behavior.
- [ ] Collapsing a panel pauses that panel's display updates; expanding restores its saved Auto state. Panel visibility does not control the simulation, whose transport controls remain in Parameters.
- [ ] Existing Random Walk strategies remain in the shared page, parameter panel, physics engine, and renderer.

## Implementation Details
Adapt the existing React Grid Layout and `FloatingPanel`/`react-rnd` behavior. Reuse `randomWalkSimLayouts` and existing persisted floating-panel state where applicable; extend persisted collapse state for docked panels. Integrate diagnostics with the panel layout rather than adding a separate route. Apply zoom as a viewport transform and render the configured finite domain in the particle view. See `memory-bank/implementation-details/random-walk-panel-workspace.md`.
