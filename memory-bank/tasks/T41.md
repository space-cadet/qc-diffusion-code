## Description
Add diagnostic plots to the existing Random Walk page so users can distinguish the physical behavior of the available strategies from their time evolution and event statistics. This is a dedicated feature task, separate from the completed T27 clean rewrite and the separate Analysis tab tracked under T17.

## Acceptance Criteria
- [ ] Plot ensemble spread over simulation time on log-log axes with an estimated growth exponent; use radius quantiles or median squared radius for Lévy runs where ordinary MSD is unstable or undefined.
- [ ] Plot jump-length and waiting-time complementary cumulative distributions with strategy-appropriate sampling and labels.
- [ ] Show radial density at multiple selected times or as a time-colored evolution view.
- [ ] Plot event count per particle over time and heading/velocity autocorrelation where those quantities have a meaningful definition.
- [ ] Add trajectory trails with visible turn, jump, and waiting-event markers.
- [ ] Compare like-for-like runs and make boundary/truncation effects clear so the plots do not imply statistics outside the simulated domain.
- [ ] Integrate the plots into the existing Random Walk UI; do not add a new page or route.

## Implementation Details
The plots should reveal complementary signatures: ballistic growth, the persistent CTRW crossover, Lévy heavy-tailed jumps, and time-fractional long waits. Use seeded ensembles and common initial conditions for comparisons. T15-specific diagnostics can consume strategy telemetry after T40 integrates `qc-diffusion-T15a` and `qc-diffusion-T15b` into the engine.
