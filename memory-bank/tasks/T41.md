## Description
Add diagnostic plots to the existing Random Walk page so users can distinguish the physical behavior of the available strategies from their time evolution and event statistics. This is a dedicated feature task, separate from the completed T27 clean rewrite and the separate Analysis tab tracked under T17.

## Acceptance Criteria
- [x] Plot ensemble spread over simulation time on log-log axes with an estimated growth exponent; use median squared radius for Lévy runs where ordinary MSD is unstable or undefined.
- [x] Plot jump-length and waiting-time complementary cumulative distributions with strategy-appropriate sampling and labels.
- [x] Show radial displacement density at multiple selected times.
- [x] Plot event count per particle over time and initial-velocity correlation where those quantities have a meaningful definition.
- [x] Add trajectory trails with visible turn, jump, and waiting-event markers.
- [x] Compare saved runs only when seed, dimension, ensemble size, initial state, boundary, speed, and event rate match; identify finite-boundary truncation.
- [x] Integrate the plots into the existing Random Walk UI; do not add a new page or route.

## Implementation Details
The plots should reveal complementary signatures: ballistic growth, the persistent CTRW crossover, Lévy heavy-tailed jumps, and time-fractional long waits. Use seeded ensembles and common initial conditions for comparisons. T15a/T15b event data now flows through the same optional strategy telemetry used by the standard strategies.
