## Description
Implement a pure, renderer-independent model for the fixed-volume spheroid $a=b=Re^q$, $c=Re^{-2q}$. Implement both a diffusive control and a persistent velocity-flip process in $q$, with injectable seeded randomness and a declared simulation clock.

## Acceptance Criteria
- [ ] Compute axes, surface metric, area element, Gaussian curvature, and axis ratio from $R,q$; verify the sphere and pole/equator formulas.
- [ ] Implement the continuous-time event-driven persistent process with speed $v$, Poisson flip rate $\lambda$, prescribed initial $q,\sigma$, and deterministic seed.
- [ ] Implement a separate diffusive control; document time discretization and its error.
- [ ] Export attempted events, event times, states, parameters, seed, and sampled display frames without frame-rate dependence.
- [ ] Check positivity, finite speed, fixed enclosed volume, and bounds/domain handling.
- [ ] Keep geometry and trajectory modules independent of React and Three.js; add focused analytic and replay checks.

## Implementation notes
Changing $q$ changes the ellipsoid's intrinsic surface metric. The selected $q$ step law is a model input. Transforming a trajectory to $r=c/a=e^{-3q}$ must not be implemented as a new equal-step walk in $r$. Reuse T38's RNG and serialization seam if available, without coupling the model to the generic particle engine unnecessarily.
